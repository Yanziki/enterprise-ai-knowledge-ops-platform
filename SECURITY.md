# Security Policy

## Supported versions

Before the first stable release, only the latest commit on `main` is supported.
Tagged release support will be documented when releases begin.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory reporting for this repository. If private reporting is not
available, contact the repository owner privately through their GitHub profile
and request a secure reporting channel.

Include the affected revision, reproduction steps, impact, and a safe proof of
concept. Allow maintainers reasonable time to investigate before disclosure.

Never include real credentials, tokens, personal data, customer documents, or
other sensitive material in issues, pull requests, logs, or demonstrations.
